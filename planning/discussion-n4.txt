12 repliesPeter Marirosans  [6:43 PM]
Morning, yes, I came across this myself while developing different use cases. I can see the benefit of being able to say that the key being used has already been verified by the smart contract, and hence I can trust it … but it can also be placed in the Agent card as additional credentials the agent holds, with more details of the scope of the key. Given that our Agent Cards are hashed on-chain… it’s the same thing… whoever updated the agent card had access to the Concordium account that owns the NFT because the hash matches whats in the registry and therefore any info in the card must be true.

So I can see making the CIS-8004 record hold multiple CIS-8 references being helpful, as it means the opposing agent can verify all the keys the agent is using with one check, rather than checking the agent card, but there is a workaround at the moment.

But definitely no need for multiple NFTs for the same agent.
